# Chord Scroll

ສະຄຣິບສຳລັບ [dochord.com](https://www.dochord.com) ທີ່ຟັງສຽງກີຕ້າຜ່ານໄມ ແລ້ວເລື່ອນໜ້າຄອດໃຫ້ເອງ
ເມື່ອແຖວທີ່ຢູ່ຖັດໄປ 2 ແຖວເບິ່ງບໍ່ເຫັນແລ້ວ. ສຽງຖືກປະມວນຜົນໃນເຄື່ອງຂອງເຈົ້າເທົ່ານັ້ນ ບໍ່ຖືກສົ່ງໄປໃສ.

## ຕິດຕັ້ງ

1. ຕິດຕັ້ງຕົວຈັດການສະຄຣິບຕາມຕາຕະລາງລຸ່ມນີ້ (ເທື່ອດຽວຕໍ່ເຄື່ອງ).
2. ເປີດລິ້ງນີ້ໃນບຣາວເຊີດຽວກັນ ແລ້ວກົດ Install:
   **[ຕິດຕັ້ງ Chord Scroll](https://raw.githubusercontent.com/TaoSivi/chord-scroll/main/chord-scroll.user.js)**

| ເຄື່ອງ | ບຣາວເຊີ | ຕົວຈັດການສະຄຣິບ |
|---|---|---|
| Android | Firefox | Violentmonkey (ຈາກ Firefox Add-ons) |
| ຄອມ | Chrome / Edge / Firefox | Tampermonkey |
| iPad | Safari | ແອັບ Userscripts (ຈາກ App Store) |

Chrome ເທິງ Android ໃຊ້ບໍ່ໄດ້ ເພາະບໍ່ຮອງຮັບສ່ວນຂະຫຍາຍ.

## ວິທີໃຊ້

1. ເປີດເພງໃນ dochord.com. ຖ້າມີໜ້າຕ່າງຂໍຄວາມຍິນຍອມ ຫຼື ໂຄສະນາບັງຢູ່ ໃຫ້ປິດກ່ອນ.
2. ຖ້າໃສ່ capo ໃຫ້ກົດ `+` / `−` ຢູ່ມຸມຂວາລຸ່ມໃຫ້ກົງກັບຊ່ອງທີ່ໜີບ.
3. ກົດ **▶ ເລີ່ມ** ແລ້ວອະນຸຍາດໃຫ້ໃຊ້ໄມ.
4. ຫຼິ້ນຕາມປົກກະຕິ. ຄອດທີ່ມີສີເຫຼືອງຄືບ່ອນທີ່ສະຄຣິບຄິດວ່າເຈົ້າຫຼິ້ນຢູ່.
5. ຈະເລີ່ມຈາກກາງເພງ: ເລື່ອນຈໍໄປທ່ອນນັ້ນ ໃຫ້ແຖວທີ່ຈະເລີ່ມຢູ່ເທິງສຸດຂອງຈໍ ແລ້ວຫຼິ້ນໄດ້ເລີຍ.
6. Intro ທີ່ຂຽນ "( 2 Times )" ຈະຫຼິ້ນຈັກຮອບ ຫຼື ຂ້າມໄປເລີຍກໍ່ໄດ້ ແອັບຟັງເອົາເອງ.
7. ຖ້າມັນຕາມຜິດ ໃຫ້ແຕະຄອດທີ່ເຈົ້າຫຼິ້ນຢູ່ຈິງ.

## ຂໍ້ຈຳກັດ

- ຄວາມແມ່ນຍຳກັບໄມ ແລະ ກີຕ້າຈິງ ຍັງບໍ່ໄດ້ປັບແຕ່ງ.
- ເພງທີ່ຂຽນ "ຊ້ຳ *" ໂດຍບໍ່ຂຽນຄອດຊ້ຳ: ຕ້ອງແຕະຄອດເພື່ອຍ້າຍຕຳແໜ່ງເອງ.
- ທ່ອນໂຊໂລ ຫຼື ດີດ picking ອາດຕາມຊ້າ.
